# Sample Conversation Log

## 1. Initial Question

**User**

Can you help me review a long Codex conversation?

**Assistant**

Yes. Export the conversation to Markdown and open it with this local viewer.

```powershell
python .\codex_log_viewer.py --log .\sample_log.md
```

## 2. Follow Up

**User**

Can I search and collapse sections?

**Assistant**

Yes. Use the search box in the sidebar and the expand/collapse controls at the top.
